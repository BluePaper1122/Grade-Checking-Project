Grade Checker

Description:

This is a Grade Checking Tool that allows the user to list your classes, store the user's grades and assignment categories on their classes, and also calculate the class grade!

List of methods:

Assignment/Grade-level manipulations:

add_grade(assignment_name, points, category) -- Allows the user to add a string assignment name, numerical points (0-100), and the category the grade belongs in.

change_grade(assignment_name, new_points, new_category) -- Allows the user to update a previous entry within the list of grades by adding a new numerical points (0-100) value and a new category (could be same as previous) that the grade belongs in.

remove_grade(assignment_name) -- allows the user to delete a grade within the list of grades.

check_added_grades() -- allows the user to check the grades they've entered in a dictionaries-in-list format.

calculate_grade() -- allows the user to calculate the current grade in percent within the class, given that all categories have at least 1 grade.

grade_converter() -- allows the user to calculate the current letter of the class based on a standard Rice University scale

Category-level manipulations

add_category(category, category_weight) -- allows the user to add a category with the corresponding category weight (between 0 and 1).

remove_category(category) -- allows the user to delete a category within the list of categories.

check_categories() -- allows the user to check the categories and weights they've entered in a dictionaries-in-list format
